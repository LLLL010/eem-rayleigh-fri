# 示例数据

文件关系：

| 文件 | 内容 |
|---|---|
| [`input/示例数据.xlsx`](input/示例数据.xlsx) | EEM 数值矩阵，`Sheet1` 第一行 Ex，第一列 Em；可复制到单独文件夹试运行 |
| [`expected/示例数据_插值后.xlsx`](expected/示例数据_插值后.xlsx) | 散射窗口插值后的绘图矩阵 |
| [`expected/示例数据_五区积分.xlsx`](expected/示例数据_五区积分.xlsx) | 五区原始积分、面积归一化积分、占比、运行记录和方法 |
| [`example_before_after.png`](example_before_after.png) | 处理前后 EEM 和五区占比的对比图 |

## 自己运行并核对

1. 新建一个空文件夹，只把 `input/示例数据.xlsx` 与 [Windows 免安装包 v1.2.0](../dist/eem-rayleigh-fri-win64-v1.2.0.zip)解压得到的 `启动处理.bat`、`eem_tool.exe` 复制进去。
2. 双击批处理文件。输出会出现在这个空文件夹的 `EEM_处理结果` 下。
3. 输出矩阵应与 `expected/示例数据_插值后.xlsx` 相同；汇总表的一行应与 `expected/示例数据_五区积分.xlsx` 一致。

不要把 `expected` 中的两个 XLSX 与输入 XLSX 放在同一个顶层文件夹里运行：程序会扫描该文件夹里的**所有** XLSX，它们会被再次当成输入。

## 图和数值如何读

对比图横轴为发射波长 Em，纵轴为激发波长 Ex。A、B 面板共用 0–400 的蓝—青—绿—黄—红显示色标；超出 400 的点仅在**图上**以最高色表示，原始和输出 XLSX 均保留实际数值。两张 EEM 图绘制时做了细网格插值和轻微平滑，**不参与散射处理或积分计算**。白线标出五区边界。C 面板为面积归一化后的五区占比，不是五区原始积分。

本例有 333 个一阶窗口点、217 个仅属于二阶窗口的点，共 550 个插值点，其中有 38 个 `9999.9` 饱和值。窗口外测量值不修改。程序没有扣空白或识别水拉曼散射，因此处理后的亮区不应自动解释为纯样品荧光。

计算与作图分别由 `scripts/build_example.py` 和 `scripts/plot_example.py` 生成，可在安装依赖后重新执行。
